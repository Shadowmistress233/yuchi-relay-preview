# 鱼池中转（RELAY STATION）首页架构与设计决策记录

## D1｜交付边界：独立视觉首页与可配置外挂
- **结论**：先交付独立静态构建的首页工程（`dist/`），将所有运营变量（倍率、控制台地址、API Base URL、微信号、二维码图片路径）收口在 `src/config/siteConfig.ts`。
- **理由**：后端控制台已就绪，视觉前端独立迭代部署最快，后续挂接 NewAPI/OneAPI 只需替换配置文件中的 URL 与文案，无需改动组件结构。

## D2｜视觉基调：50% 二次元星图机能 × 50% Chrome 滚动叙事
- **结论**：采用白昼档案底（`#F4F6FB`）与星夜深空底（`#12183E` / `#0C1029`）交替分段，辅以香槟星轨金（`#E2BE70`）与天琴座几何刻度线。
- **理由**：忠实延续海报视觉基因，同时避免纯黑底或泛滥霓虹渐变带来的「野鸡站/AI 模板感」，兼顾第一眼惊艳度与资费说明的可读性。

## D3｜模型定位：纯血满血 GPT 三剑客
- **结论**：聚焦 `GPT-6.2 Sol`、`GPT-6.2 Astra`、`GPT Image 2.6`，不混杂其他厂商模型作为主视觉。
- **理由**：与龙娘看板娘（GPT 拟人原设，致敬 `ZipZipPipe`）形成统一世界观，突出「专精满血 Responses API + 防降智透传」的差异化壁垒。

## D4｜定价与转化口径：0.17 倍率按量计费 + 1:1 远程支持
- **结论**：以 `0.17x` 倍率免月租按量计费为核心算账锚点，转化采用「控制台登录 + 微信 1:1 远程包配好」双轨入口。
- **理由**：直接击中官方 Plus（\$20）/ Pro（\$200）固定月租贵与国内配置门槛高的痛点。

## D5｜客户端生态策略：主推 CC Switch，规避 Cursor 硬伤
- **结论**：重点展示通过 `CC Switch` 一键切换 `Codex CLI / App`（保留官方 `auth.json` 登录态）、`OpenCode`、`Cherry Studio`、`Roo Code` 与原生 SDK，不把 Cursor 作为主打承诺。
- **理由**：Cursor 自定义 Base URL 存在需 Pro 订阅、不支持 Tab、全局路由冲突及 Responses API 兼容问题，主推 `CC Switch` 既专业又能大幅降低 1:1 远程售后成本。

## D6｜双端动效策略：Chrome 式 `gsap.matchMedia()` 双轨分流
- **结论**：桌面端（`>=1024px`）启用 GSAP `ScrollTrigger` 锁屏叙事与鼠标星盘视差；移动端（`<1024px`）自动关闭长距离 `pin`，降级为流畅的触控 Tab 与卡片流。
- **理由**：兼顾桌面大屏展示上限与微信内置浏览器/手机端滚动的 60fps 顺滑体验，避免地址栏伸缩引起的锁屏抖动。

## D7｜美术资产管线：OpenAI `gpt-image-2.6-sunburst` 原生透明通道直出
- **结论**：以原海报右半侧白龙娘为基础运行图生图，生成原生 `transparent` Alpha 背景高清立绘与 3 张 `Image 2.6` 实机样张。
- **理由**：保证看板娘跨屏形象一致，同时用真实 API 产出直接充当「图像 03」画廊的硬核活广告。

## D8｜预览托管选型：GitHub Pages（Public 预览仓）+ WebP 静态加速
- **结论**：将静态工程推送至 `Shadowmistress233/yuchi-relay-preview`（Public），通过 GitHub Actions 自动构建发布到 GitHub Pages，并将 `public/assets/*.png` 转换为高画质 `.webp`（完整保留 Alpha 透明通道）及配置 `base: "./"`。
- **理由**：本机 `gh` 已就绪、零额外平台配置成本即可获得公网分享链接；`WebP` 压缩大幅降低首屏加载体积，同时保留同学直接 `git clone` 接手并挂入正式 nginx 域名的便利性。
